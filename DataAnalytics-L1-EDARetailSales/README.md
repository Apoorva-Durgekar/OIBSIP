## How to Run
1. Clone this repository
2. Navigate to this folder: `OIBSIP/DataAnalytics-L1-EDARetailSales/`
3. Install requirements: `pip install pandas matplotlib seaborn jupyter`
4. Open the notebook: `jupyter notebook EDA_Retail_Sales.ipynb`
5. Update the `FILENAME` variable to match your downloaded CSV name
6. Run all cells in order
